# 📝 iTask - Todo App

A simple and responsive Todo App built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Features

* ➕ Add new todos
* ✏️ Edit todos
* 🗑️ Delete todos
* ✅ Mark todos as completed
* 👀 Show/Hide completed todos
* 💾 Save todos in Local Storage
* 📱 Responsive design

## 🛠️ Technologies Used

* React
* Vite
* Tailwind CSS
* JavaScript
* React Icons
* UUID
* Local Storage

## ⚙️ Installation

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.

## 💡 About

iTask is a simple Todo application created to practice **React state management, components, Tailwind CSS, and Local Storage**.
